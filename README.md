## StudentHive – Student Event Registration Form

StudentHive is a student-focused website designed to simplify campus event registration. The registration form allows students to enter their personal details, including name, gender, date of birth, age, email address, and mobile number, and select an event.

Built using **HTML, CSS, and JavaScript**, the form includes input validation to ensure that users provide valid information. It displays error messages for invalid or missing fields and confirms successful registration when all required validations are passed. The responsive design provides a clean and user-friendly experience across different screen sizes.

**Key Features:**
- Student personal details registration
- Gender selection and date of birth input
- Email and 10-digit mobile number validation
- Name format and required-field validation
- Terms and conditions checkbox validation
- Error messages and success confirmation
- Responsive design using CSS

**Technologies Used:** HTML, CSS, JavaScript
